## 📌 Problem Statement
Students today face immense academic pressure, leading to burnout and anxiety. Many hesitate to seek professional help due to stigma, cost, or lack of availability.

## 💡 The Solution
**MindMate** is an intelligent, 24/7 mental health first responder tailored for students. Built on Google's **Gemini 2.5 Flash** model, it provides instant, empathetic, and context-aware support to help students manage stress and organize their academic lives.

## ✨ Key Features
* **Empathy Engine:** Uses custom prompting to act as a compassionate listener, not just a robot.
* **Context Retention:** Remembers previous messages in the conversation (e.g., if you mention exams, it remembers that later).
* **Instant Access:** No login barriers—help is just one click away.
* **Secure:** API Keys are managed via secure cloud secrets.

## 🛠️ Tech Stack
* **AI Model:** Google Gemini 2.5 Flash
* **Frontend:** Streamlit (Python)
* **Backend Logic:** Python 3.10
* **Deployment:** Streamlit Community Cloud
